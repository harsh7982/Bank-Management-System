# 🏦 Bank Management System

A desktop-based banking application developed using Java Swing and MySQL.  
This project provides essential banking functionalities with a user-friendly graphical interface.

## 🚀 Features
- User Login Authentication
- Deposit & Withdraw Money
- Fast Cash Service
- Balance Enquiry
- PIN Change
- Mini Statement

## 🛠️ Technologies Used
- Java
- Swing
- JDBC
- MySQL

## ⚙️ How to Run
1. Clone the repository
2. Open the project in IntelliJ IDEA
3. Configure MySQL database
4. Run `Login.java`
